# 终端伪装小说阅读器

> 在终端里假装敲命令，实际在读小说。

把小说正文按页渲染成「命令行 + 调试输出」的样子：每页有假命令、缩进过的正文、行号/时间戳/路径前缀、零散分布的噪声行，配色也照着终端来。
旁人扫一眼屏幕，看到的是在跑构建、装依赖、翻日志——而不是在看小说。

## 特性

- **11 种伪装皮肤**：`cmd_type` / `path_lineno` / `log_ts` / `build_out` / `pip_inst` / `py_trace` / `tail_n` / `git_stat` / `docker_step` / `test_case` / `http_access`，每 2 页自动轮换一种，页内风格统一
- **伪装不碰正文**：只在段落前加前缀和缩进，正文一个字都不改（自检里有「正文零损伤」断言把这条钉死）
- **终端配色**：提示符亮绿、命令亮青、参数亮黄、错误亮红、时间戳亮蓝…… 有 VT 支持时走 ANSI，老 conhost 自动退回 `SetConsoleTextAttribute` 分段写色
- **伪装密度可调**：每页正文之间夹 2~3 条假命令（紧跟命令的正文自然读成它的"输出"），3~6 条噪声行散布在各处，行内前缀每 2~5 行抽 1 行，且只落在段落第一行前——绝不劈开句子
- **3 档输出速度**：整行瞬现（像真终端刷屏）/ 常规 / 逐字打字，`v` 键轮换
- **自动分章 + 目录**：按 `第X章` / `Chapter N` 等模式切分，`t` 键呼出目录直接跳章
- **书架 / 进度 / 书签**：自动记住读到哪一段，下次打开接着读；`b` 加打点，`l` 翻打点
- **导入 txt 有独立界面**：可以手输路径，也可以当文件浏览器用（换盘符、进目录、翻着挑）
- **纯标准库**：零第三方依赖，`python terminal_reader.py` 直接跑；也能用 PyInstaller 打成一个 exe 丢到没装 Python 的机器上
- **每个功能都有单字节字母键兜底**：不依赖方向键/PgUp（不同终端对这些键的编码差得离谱，本项目为此踩过三次坑）

## 环境

- **Windows**：用的是 Win32 控制台 API（备用屏、`WriteConsoleW`、改字体字号），Linux/macOS 跑不起来
- **Python 3.8+**，无第三方依赖
- conhost 与 Windows Terminal 都可用；没有 VT 支持的老 conhost 会自动切换配色后端

## 用法

```bat
python terminal_reader.py                    :: 直接进书架
python terminal_reader.py D:\books\abc.txt   :: 打开指定小说
reader.bat D:\books\abc.txt                  :: 或把 txt 文件直接拖到 reader.bat 上
```

命令行参数：

| 参数 | 作用 |
| --- | --- |
| `<文件>` | 可选。要打开的小说；不给就进书架 |
| `--speed fast\|normal\|slow` | 输出速度，默认 `fast` |
| `--preview N --size 100x30` | 把第 N 页渲染到标准输出（不需要真终端，方便截图和自检） |
| `--selftest` | 非交互自检 |
| `--probe` | 打印终端能力（VT / 尺寸 / 字体） |
| `--keytest` | 交互式按键诊断，排查「按键没反应」 |

## 按键

**阅读页**

| 键 | 作用 |
| --- | --- |
| `空格` / `n` / `j` | 下页（正文打字中则先把当前页打完） |
| `p` / `k` | 上页 |
| `t` | 目录 |
| `f` | 书架（工作区文件列表） |
| `s` | 搜索 |
| `g` | 跳到指定百分比 |
| `b` | 当前位置加书签 |
| `l` | 书签列表 |
| `c` | 命令模式（`: ` 亦可） |
| `o`（或 `i`） | 导入其它 txt |
| `+` / `-` | 字号增减 |
| `r` | 换一种伪装 |
| `v` | 切换输出速度 |
| `?` / `h` | 帮助 |
| `q` | 退出 |

**所有列表（目录 / 书架 / 搜索 / 书签 / 帮助）**

| 键 | 作用 |
| --- | --- |
| `j` / `k` | 上下移动 |
| `空格` / `n` | 下翻一屏 |
| `p` | 上翻一屏 |
| `g` / `e` | 跳到首 / 尾 |
| `Enter` | 进入当前高亮项 |
| `d` | 删除当前项（书架里 = 移除这条记录，**磁盘上的 txt 和已打的点都不动**；书签列表里 = 删掉该打点） |
| `Esc` / `q` | 返回 |

**导入界面**（阅读中按 `o` 进入）：`1` 或 `p` 手工输入路径；`2` 或 `f` 列文件夹翻找；`Esc` / `q` 返回。

**文件浏览器**：`j` / `k` 选择，`Enter` 进目录或直接导入文件，`Backspace` 回上级，`w` 跳到别处（可直接输盘符如 `D:\`），`Esc` 取消。

## 打包成 exe

```bat
pip install pyinstaller
python -m PyInstaller --onefile --console --name terminal_reader --specpath . --distpath .\dist --workpath .\build --noconfirm terminal_reader.py
```

产物是 `dist\terminal_reader.exe`（单文件，约 7 MB）。onefile 冷启动约 2 秒（要先解压到 `%TEMP%\_MEI*`），在意启动速度可以换成 `--onedir`。

## 自检

```bat
python terminal_reader.py --selftest
```

覆盖编码识别、分章、分页、伪装渲染、配色分段、书架增删、书签、导入界面与按键解析，全部通过时打印 `全部通过`。改动后请先跑这个。

## 常见问题

- **按键没反应 / 方向键显示「按键未识别」**：跑 `python terminal_reader.py --keytest`，面板会把读到的原始字节以十六进制画在提示行下方。换单字节字母键（见上表）永远不会有这个问题。
- **杀软报毒**：PyInstaller onefile 的常见误报，加白名单即可。不放心的可以直接跑 `.py` 脚本。
- **输出重定向到文件时报 GBK 编码错**：程序启动时已把 stdout/stderr 的编码错误策略降级为 `replace`；真控制台走 Unicode API 写屏，不受影响。
